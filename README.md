# Geolocalizador de Ubigeo

Este proyecto permite obtener latitud y longitud de una dirección desde Google Sheets usando Google Apps Script y la API de Google Maps.

# ¿Cómo usarlo?

1. Abre tu hoja de cálculo de Google Sheets.
2. Agrega 3 columnas "Direcciones", "Latitud", "Longitud".
3. Ve a "Extensiones > Apps Script".
4. Pega el código del archivo "codigo.js".
5. Ejecuta la función "obtenerUbicacion()".

# Tecnologías utilizadas
- Google Sheets
- Google Apps Script
- API de Google Maps
